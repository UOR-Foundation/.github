# UOR Brand Asset Concepts

> **PLACEHOLDER ONLY. NOT AN APPROVED UOR BRAND LIBRARY.**

These source-editable SVG concepts are design candidates for UOR Foundation
READMEs. They do **not** replace existing Foundation logos or approved artwork.

## What is here?

- Eleven placeholder README banner variants, including the Foundation,
  Framework, Prism, Comms, LexLean, PrismPM, R4, template, UORust,
  UOR-ADDR, and a generic repository.
- Ten generic placeholder icons. They do not represent official product logos.
- [Provisional design tokens](tokens.placeholder.json) and
  [the machine-readable inventory](placeholder-manifest.json).

The separate downloadable raster concept pack also contains social,
release, documentation and background variants. That pack has **not**
been uploaded to this repository; the SVGs here are independent editable
placeholder concepts, not pixel-identical conversions of the raster pack.

## Using an asset temporarily

1. Use only a file explicitly named `-PLACEHOLDER.svg`.
2. In the consuming README, label it *Illustrative placeholder artwork,
   pending UOR Foundation brand review*.
3. Keep actual workflow badges linked to actual workflows. Do not use
   static badge images to claim successful CI, security, release or audit.
4. Prefer local, reviewable copies of approved final exports over unpinned
   remote images.
5. Preserve existing identity and governance files. This library is a
   draft, not a mandate to replace an existing logo.

## Approval requirements

Record the Foundation brand/design owner's approval, source identity,
permission to use any underlying art, supported product claims, accessibility
review, final export versions, and checksums before promoting a candidate.
Approved assets must have a separate manifest and explicit status change.
Renaming a file is **not** approval.

The repository-specific README Architect quality standard is independent
of these assets. The skill defines quality; this library supplies candidate
visual material and documented limits.
