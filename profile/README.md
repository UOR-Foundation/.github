# UOR Foundation

The UOR Foundation stewards the **Universal Object Reference (UOR) framework** and supports related open-source projects. This page helps readers find the right source repository, documentation, and contribution rules.

UOR projects serve different purposes and are at different stages. Each repository's own documentation and evidence define what is implemented, verified, or still experimental.

## Find your starting point

- **Understand the UOR ontology:** [uor-framework](https://github.com/UOR-Foundation/uor-framework) is the Rust workspace for the ontology, exported representations, and conformance tools.
- **Explore the Prism standard library:** [prism](https://github.com/UOR-Foundation/prism) is the library façade exposing Foundation and Prism components.
- **Work with controlled-language models:** [lexlean](https://github.com/UOR-Foundation/lexlean) contains LexLean source, examples, the language contract, and verification evidence.
- **Explore model-to-artifact generation:** [prismpm](https://github.com/UOR-Foundation/prismpm) documents the model compilation workflow and acceptance boundaries.
- **Begin a Prism application:** [template](https://github.com/UOR-Foundation/template) provides the starting template, model and conformance structure, and development instructions.
- **Explore Rust-to-Prism translation:** [UORust](https://github.com/UOR-Foundation/UORust) documents Cargo-workspace modeling, unsupported cases, and proof boundaries.
- **Work with typed content addressing:** [uor-addr](https://github.com/UOR-Foundation/uor-addr) contains addressing implementations and usage guidance.

These are entry points, not an exhaustive inventory or a shared certification statement. Follow each repository's README, release information, and verification records for its current capabilities.

## Contribute and participate

The Foundation's GitHub policies and contributor instructions are maintained in the [organization's `.github` repository](https://github.com/UOR-Foundation/.github):

- [Contributor guide](https://github.com/UOR-Foundation/.github/blob/main/CONTRIBUTING.md): how to propose changes.
- [Governance framework](https://github.com/UOR-Foundation/.github/blob/main/governance/GOVERNANCE.md): roles, repository tiers, and change control.
- [Repository standards](https://github.com/UOR-Foundation/.github/blob/main/STANDARDS.md): naming, tagging, and minimum requirements.
- [Project lifecycle and oversight](https://github.com/UOR-Foundation/.github/blob/main/toc/README.md): project review and progression.
- [Security reporting](https://github.com/UOR-Foundation/.github/blob/main/SECURITY.md): how to report a vulnerability.
- [Community model](https://github.com/UOR-Foundation/community): the Foundation's community governance modeled as a Prism application.

Choose the repository closest to your proposed change, review its local contribution instructions, and open an issue or pull request according to that repository's rules.
